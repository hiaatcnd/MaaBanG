# 开发入门

环境安装、目录说明和校验命令见[项目 README](../../../README.md#开发指南)。模块职责、新增任务步骤、日志诊断与验证范围见 [Agent 开发](agent.md)，各功能专题入口也集中在该页。

新增任务时，先用 Maa Support Crop Tool 获取框架截图，裁剪稳定图标到 `assets/resource/image/`，将 ROI 写入 pipeline 识别节点；动态数字使用 OCR。ROI 是截图上的 x、y、宽、高，应使用框架归一化后的图像坐标。

先验证识别，再添加点击动作和页面转换。按[点击结果确认与补点约定](agent.md#所有点击都需考虑结果确认和补点)定义成功状态、等待期限和有限恢复；涉及资源消耗时必须识别费用、确认结果，并处理资源不足及停止操作。

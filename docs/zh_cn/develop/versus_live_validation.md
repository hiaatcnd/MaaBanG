# 竞演演出验证（2026-10-16）

## 范围

在「Maa代打演出」增加独立的竞演模式，支持普通／特别类别与活动歌曲／自由选歌房间。自由房间使用独立的歌曲配置和共享中国服歌曲目录，支持指定歌曲或不指定歌曲；活动房间忽略隐藏的自由选歌设置。最终演奏仍以房间实际曲目、难度和开演前火数预览为准。

测试账号运行于 MuMu，ADB `127.0.0.1:16384`，原始画面 2560×1440，框架截图 1280×720。使用正式 `ChartLive` 自定义动作和生产演奏进程，预先保存 0 火、关闭 Fever、代打推荐设定；未消耗饮料或星石。测试结束后返回主页。

## 修复与回归

- 每日演出报酬的多项选择不再交给通用通知确认；尚未选择时给出明确提示，不替用户选取奖励，不重复点击未启用的确定按钮。
- 已确认结果后若返回房间选择页，先结束结算，再处理一般底部按钮，避免误点该页的「确定」重新匹配。真实房间页和判定页截图回放覆盖计次去重与不再点击的边界。
- `tests/fixtures/versus` 保存活动房间、自由房间、选曲、最终准备、关闭演出背景后的准备页、每日奖励选择框和稳定判定页。通过生产 OCR 验证房间、歌曲、难度、火数预览、指定歌曲只提交一次及结算。
- 竞演追加在原有演出模式列表末尾，保留已有模式的顺序；独立选歌绑定使用歌曲 ID，不复用协力选歌参数。
- 继续共用联网房间累计 3 分钟超时、掉房退避重试、停止触控、谱面校验与 SPECIAL 不可用时使用 EXPERT 的规则。本次未人为触发竞演断线、账号限制或超时；这些仍以既有联网回归检查为证据。

本地全量 689 项测试通过（`PYTHONUTF8=1`，记录 `debug/versus-live/tests-full-utf8.log`）。首次全量运行有一项开发启动器子进程输出编码错误，统一 UTF-8 后全量重跑通过。资源检查使用缓存的 MaaFramework 5.12.3 通过，全部 pipeline 与 interface 的 JSON Schema 检查通过；生成界面可从生成器复现。模式顺序调整后另行复测竞演与共享目录检查。

## 验证入口

```text
python tools/run_chart_live.py --adb <adb路径> --address <设备地址> --mode versus --versus-room event --versus-room-group special --difficulty1 expert --max-rounds 1
python tools/run_chart_live.py --adb <adb路径> --address <设备地址> --mode versus --versus-room free --difficulty1 expert --max-rounds 1
```

自由房间可加 `--versus-song <中国服目录歌曲ID>` 指定提交歌曲。需要先用独立的演出预先设置保存火数；命令不覆盖游戏内的火数。联网房间可能自动开演，禁止 `--prepare-only`。

本节记录发布前的源码、资源和实机验证。2026-10-16 本地预览安装版已同步并通过内置 Agent、竞演入口与歌曲选择器加载检查，配置和缓存保留；正式发布包另行验证，不能用开发运行或预览包结果代替。

## 加载遮挡准备按钮的回归

2026-10-17 的运行在完成 5 轮后，第 6 轮选曲和准备阶段持续显示 `NOW LOADING`。准备按钮区域无法识别，游戏自动开演后程序仍停在等待最终确认，最终以未知页面超时结束。

- 协力／竞演准备按钮被遮挡时，同时核对底部完整的四个基础难度标签与歌曲等级位置，再进入原有歌曲、所选难度、火数预览及演出设置检查；加载提示本身不能授权演奏。
- 通过开演检查后，演奏进程先获得监听授权。准备按钮仍被遮挡时不点击加载提示，等待房间自动开演；如果提交准备前已经进入舞台，也继续交给已授权的演奏进程。
- 无法确认页面或选曲按钮持续未加载时，协力／竞演约 8 秒后退出当前房间，再走既有的退避重试。加载计时不被背景中的「选择中」重置。恢复时识别选曲、抽选和加载页；完全未知的房间页面短暂等待后仅尝试一次已有的切后台退出方式，并继续确认返回状态。
- `tests/fixtures/versus/song_loading.png` 和 `unattended_stage.png` 是本次失败的原始截图。准备阶段没有留存截图；测试将原始加载提示覆盖到已有准备页上，明确作为遮挡模拟回放，验证生产 OCR、歌曲／难度／火数检查、完整父进程开演授权和禁止点击遮挡层。触控进程使用替身，没有启动游戏或进行实机演奏。

相关的联网、竞演、协力、演出设置和直接谱面回归共 142 项通过，记录见 `debug/online-loading-tests.log`。本次为源码与离线回放验证，尚未同步安装版或验证实机自动开演。

## 当前歌曲与选项对齐（2026-10-18）

- 协力和竞演自由选歌房间新增「选择当前歌曲」：进入房间选歌页后，直接提交该页当前选择，不进入自由演出预选、不改筛选或收藏、不做列表曲名 OCR。每轮以该页当前选择为准，不锁定第一次提交的歌曲。加载中等待；页面、按钮或可用状态未确认时不提交。
- 竞演的歌曲和收藏选项移到与房间类别、房间类型同一层级，与协力保持同样的选项排列。活动歌曲房间忽略歌曲和收藏设置，最终歌曲仍由游戏决定；共用难度、随机偏差、避免 Full Combo、次数和补火设置。
- 开演前继续识别房间最终曲目、难度和火数预览。当前歌曲模式未提交成功时，不能直接进入最终确认；未改动结算、计次及掉房重试边界。
- 协力和竞演的下拉框按「不指定歌曲 → 选择当前歌曲 → 具体歌曲」显示。展开后的内部数据仍将新的静态选项追加在末尾，保留原歌曲索引；界面按歌曲对象恢复选择，选择后映射回原索引。旧竞演房间内保存的选歌与收藏设置在默认值生成前迁移。已有共享收藏设置与旧竞演设置冲突时，保留当前演出模式正在使用的偏好。竞演加入曲库动态刷新与歌曲身份映射。

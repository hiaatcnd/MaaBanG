# 谱面演出功能集成验证

## 当前范围

新任务 ChartLive 独立于游戏内自动额度，包含自由演出、自由巡演和课题巡演，三首歌曲及难度可独立配置。目录为中国服 734 首、3070 张实际开放谱面。五个偏差档位均非零；火数 0–3，道具补火可选；巡演完整三首计一次。

## BPM 兼容性

全目录检查发现官方 585 号谱面重复声明相同 BPM，667 号谱面在 beat 0 依次声明 97 和 103 BPM。编译器现按源文件顺序保留同一拍的最后一个 BPM。

该处理核对了 [Bestdori 模拟器](https://bestdori.com/tool/chartsimulator) 当前脚本 `ToolChartSimulator.95b33d9b.js`：按 beat 稳定排序后逐条构建时间映射，同一拍的最后一条优先。不按 BPM 数值排序，也不将这些有效谱面拒绝为冲突。相同 BPM 重复和不同 BPM 重复均有测试。

## preview4 乐队与等级筛选

本节记录历史版本；其中软件内增加筛选配置的设计已在 preview5 按用户澄清撤销。

Maa代打演出和清火自动演出共用选歌模块：先离开收藏/曲风分类，恢复筛选条件，选择目标乐队并确认选中状态，以 EXPERT 搜索避免 SPECIAL 隐藏歌曲，再切换实际演出难度。联合演唱及没有独立按钮的乐队使用游戏内“其他”分类。当前歌曲已匹配时直接复用，不重新滚动列表。

软件配置提供“乐队 → EXPERT 乐曲等级 → 歌曲 → 实际演出难度”，前两项均可选“不限”；自由巡演三个位置独立配置，课题巡演固定歌曲不受此筛选影响。清火自动演出取消收藏要求，仍使用游戏内自动额度与原有消耗规则。

116 项测试及 schema 校验通过，组合筛选测试覆盖完整 734 首目录。实机选歌检查：清火任务通过“其他”分类选中 SAVIOR OF SONG / EXPERT（约 31.5 秒），Maa代打通过 Pastel＊Palettes 选中 きゅ〜まい＊flower / SPECIAL（约 12.2 秒），均进入正确准备页并返回主页。只验证选歌，没有开始演出，没有消耗火、道具或自动额度。证据 `debug/chart_band_selection/report.json`；耗时为本次单次观察，没有同条件旧版测速，不宣称固定加速倍数。

## preview5 游戏内自动筛选

软件恢复直接选择歌曲与难度，删除乐队和 EXPERT 等级的用户配置。选定歌曲后，程序自动在游戏中按所属乐队、EXPERT 难度和该谱面的精确等级筛选；读取区间两端确认相等后才查找。等级滑块先跨过触控拖动阈值再回到目标位置，避免小幅移动被游戏忽略。若最终选择其他难度，先恢复等级范围为 5～30，再切换难度，防止目标歌曲因难度等级不同被过滤掉。

两种任务的实机选歌复验通过：SAVIOR OF SONG 自动筛选“其他”与 EXPERT 28～28；きゅ〜まい＊flower 自动筛选 Pastel＊Palettes 与 EXPERT 26～26，找到后解除等级限制并正确选择 SPECIAL 27。均只进入准备页并返回主页，无资源消耗。证据 `debug/chart_band_level_selection/report.json`。118 项回归及 schema 校验通过；不宣称所有歌曲实机已测。

另将任务显示名称改为“解锁3D演出服饰”，解锁范围与原行为不变。

## preview6 截断正态偏差

时间偏差由“正态抽样后压到边界”改为越界重新抽样，水平和垂直位置由均匀分布改为同样的截断正态分布。均值 0，标准差为各自档位上限的 1/3；现有档位上限不变。同押共享时间偏差，整条手势共享时间与位置偏移，用户仍不能关闭随机偏差。

使用真实编译出的 12,000 个单键检查分布：时间偏差落在 ±1σ 内为 67.875%，±2σ 内为 95.458%；水平和垂直位置分别约 68.592% / 68.033% 与 95.842% / 95.833%。无样本被堆到边界。120 项回归、schema 检查及 56 张代表谱面的五档触点/边界检查通过，覆盖高难度、不同首键和重复 BPM。报告 `docs/data/chart_normal_jitter_validation.json`；本次未实机开演，不消耗火或道具。

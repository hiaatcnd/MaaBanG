# 技能长按与技能滑条首键验证

## 原因和修复范围

`first_anchor` 原先在读取技能标记前，先把所有 Long/Slide 头归为绿色。歌曲 781 NORMAL 的首键实际为金色技能长按头，导致未锁定、未发送触控、MISS 掉血后停止。

此次调整技能头的颜色选择；联机技能长按／滑条保留绿色外观兼容，分别提取金色和绿色候选，避免两个颜色掩码合并后把键头与长条连成过高区域。同步时间模型、普通音符、滑键优先规则及轨迹身份保护继续使用现有实现。Directional 不属于此次修复范围。

## 证据

- 修复前在 MuMu 复现两次：781 NORMAL，0 火，首键锁定前生命减少，0 次触控，画面 MISS、900/1000 生命。
- 录制帧收入 `tests/fixtures/chart_sync/eat_past_skill_hold.json` 及配套 PNG。按正确键色回放，首键提前约 155 ms 锁定。
- 修复后 781 NORMAL：259 PERFECT，其他判定均为 0，ALL PERFECT；1,458 次触控事件均成功，完成结算。
- 修复后 682 EXPERT《八芒星ダンス》：760 PERFECT、1 GREAT、0 GOOD/BAD/MISS，761 COMBO；完成结算。
- 上述两局使用 0 火，未补充火或使用星石；测试后恢复原有 3 火设置。
- 审计本地 3,080 份缓存谱面，单人首键选择发生变化的 10 份谱面均属于技能长按／技能滑条开头。

## 回归边界

单元测试覆盖 Single/Long/Slide 的技能与非技能头、单人/联机、普通滑键、Directional 原有规则、同拍普通单点优先、较晚单点不得取代首拍、尾部技能标记不得影响首键，以及长条掩码不合并、误锁尾部拒绝。

录制回归包括金色技能长按、普通绿色长按、单人金色技能单点、联机普通色技能单点和原有亮色滑键。联机技能长按的兼容性是离线回放与合成轨迹验证，不代表新增联机实战验证。

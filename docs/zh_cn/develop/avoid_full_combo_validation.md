# 避免 Full Combo 实机验证

日期：2026-10-07。使用当前工作区源码、MaaFramework 5.12.2、MuMu `127.0.0.1:16416`，原始画面 2560×1440，内部识别与触控坐标 1280×720。本记录不是正式发行包验证。

## 最终规则

开关默认关闭。开启后按谱面时间跳过最后一个独立的普通键或滑键（`Single` / `Directional`）；所有长条、滑条及其滑键尾端完整演奏。同押只跳过一个符合条件的音符。没有独立音符时，在开演前报错停止。

## 实机结果

通过正式任务入口 `ChartLive` 运行，每次限一轮，歌曲为 `306 / SAVIOR OF SONG`。预先应用速度 9.80、默认皮肤、关闭镜像、0 火及关闭 Fever；随机偏差为“极小偏差”。三局均正常结算并返回主页，没有补火。

| 场景 | PERFECT | GREAT / GOOD / BAD | MISS | 最大连击 | 触控事件 |
|---|---:|---|---:|---:|---:|
| EASY，关闭开关，对照 | 133 | 0 / 0 / 0 | 0 | 133 | 238 |
| EASY，开启，末尾长条前跳过普通键 | 132 | 0 / 0 / 0 | 1 | 130 | 236 |
| NORMAL，开启，跳过末尾普通键 | 245 | 0 / 0 / 0 | 1 | 245 | 442 |

EASY 对照获得 ALL PERFECT。开启后的两局均未 Full Combo，判定由结算截图人工核对。

EASY 跳过第 275.5 拍、轨道 1（从 0 开始计数）的普通键，基准时间 86.09375 秒。之后第 278～279.5 拍、轨道 3 的长条完整演奏：实际按下时间 86.8750767 秒，抬手时间 87.3518267 秒。仅目标普通键的按下、抬手被省略。

NORMAL 跳过第 279.5 拍、轨道 3 的普通键，基准时间 87.34375 秒。

逐条用每局记录的随机种子重建触控计划，与实机 `playback.json` 比较：三局所有实际触控均匹配；所有触控 API 成功，没有调度恢复或残留触点。开启时其余音符与同种子的完整计划逐条一致。

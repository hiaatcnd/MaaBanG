# Maa代打演出

在任务列表选择 **Maa代打演出**。它读取 Bestdori 谱面并发送触控操作，不消耗游戏内置自动演出的次数。开演前会关闭游戏内置自动。

## 使用

1. 启动 MuMu 的安卓 15 实例，将游戏设为 16:9 横屏，在 MaaBanG 中连接该实例。
2. 进入游戏主页或演出菜单，选择任务模式、歌曲及实际演出难度。无需额外选择乐队或等级。歌曲必须已在游戏内解锁，无需事先收藏。
3. 选择随机偏差、每首消耗火数、火不足策略和最大演出次数，然后启动任务。

两种演出任务都会自动读取所选歌曲的乐队和 EXPERT 等级，在游戏内筛选后查找；联合演唱等使用“其他”分类，不限制收藏。找到歌曲后，若实际演出难度不是 EXPERT，会先解除等级限制，再切换到指定难度。自由巡演分别查找三首歌；课题巡演直接使用固定歌单。

首次使用某张谱面需要联网访问 Bestdori，成功下载的谱面缓存在 `%USERPROFILE%\.maabang\cache\charts`，与任务、设备配置一起跨版本复用。首次启动会迁移当前包及相邻 MaaBanG 包中的旧缓存，原文件保留；已有共享配置不会被旧包覆盖。通过 `MAABANG_DATA_DIR` 可指定独立的数据目录。下载失败或谱面与目录不一致时，会在开演前停止。

| 模式 | 选曲与难度 | 次数如何计算 |
|---|---|---|
| 自由演出 | 自选一首歌和难度 | 一首计一次 |
| 自由巡演 | 三首歌曲、三首难度分别选择，可以重复选歌 | 完整三首计一次 |
| 课题巡演 | 自动读取游戏左侧课题巡演的固定三首，三首难度分别选择 | 完整三首计一次 |
| 团队演出 | 游戏随机选曲，无房型和选曲设置；选择演出难度 | 成功结算一首计一次，退出重试不计次 |

自由及巡演模式不会替换难度；课题歌曲没有所选难度时会停止。团队演出选择 SPECIAL 时，如果最终歌曲没有 SPECIAL，则降为 EXPERT，并在日志中记录实际难度。

## 团队联网演出

协力演出暂缓，当前只开放团队演出。选择团队模式、难度、火数、火不足策略与最大次数即可；歌曲由游戏随机决定。

当前活动的实机演奏、掉房重进和 3 分钟超时验收见[团队演出验证记录](develop/team_live_validation.md)。

进房前完成演出设置和火数检查。识别最终歌曲并确认实际难度后，优先校验共享缓存；缺失时只下载这一首、这一难度的谱面，不提前下载整个曲库。谱面准备期间持续检查停止操作和房间状态；准备超过 12 秒、下载或校验失败时退出房间并停止任务，只有校验完成且最终确认页面仍有效时才提交准备。自由演出只准备所选单曲，巡演只准备本轮三首。

从匹配开始累计 3 分钟没有实际开演就退出重进；选曲、加载及“其他成员正在准备中”都不会重置计时。确认开演后不再使用这个超时。掉房或返回主界面时会停止并释放触控，再重新读取火数和匹配。连续重试间隔为 3、6、12、24、30 秒，之后维持 30 秒；成功结算后重置。

只有成功结算才增加完成次数。中途退出即使已经扣火，也不算完成；重试以实际火余额为准。无法确认歌曲、谱面、难度、维护／账号限制或未知页面时停止并保留现场，不猜测谱面。演奏使用与自由演出相同的首键同步和持续校时。

## 分辨率

要求游戏画面为 16:9 横屏。已确认当前模拟器原始分辨率为 2560×1440，演奏控制器会将截图自动缩放为 1280×720；识别和触点都使用这套内部坐标，MaaFramework 再按比例换算回设备坐标，无需把模拟器改为 1280×720。表中的位置偏差也以内部 1280×720 坐标为单位。

2560×1440 的截图缩放已在当前实例验证；其他 16:9 分辨率沿用同一换算机制，尚未逐档实测。非 16:9 画面会在开演前停止。

## 随机偏差

每个档位都有非零的时间和位置偏差，没有关闭选项。时间、水平和垂直位置均采用以 0 为中心的截断正态分布：标准差为各自上限的 1/3，越界则重新抽样，不压到边界。约 68% 的偏差落在上限的 ±1/3 内，约 96% 落在 ±2/3 内，较大的偏差更少出现。同押共享时间偏差，整条长按、滑条保持同一组偏移，避免手势断裂。

| 档位 | 时间偏差上限 | 水平位置偏差上限 |
|---|---:|---:|
| 极小偏差 | ±3 ms | ±1 px |
| 小偏差 | ±9 ms | ±3 px |
| 中等偏差 | ±35 ms | ±6 px |
| 中大偏差 | ±60 ms | ±9 px |
| 大偏差 | ±90 ms | ±12 px |
| 很大偏差 | ±180 ms | ±22 px |

极小偏差优先准确，但不保证 ALL PERFECT。大偏差可能明显出现 GOOD、BAD、MISS，甚至因生命耗尽而结束演出。偶发漏键属于当前接受范围，不会为了全连自动重开。

## 火数、补火和次数

每首可选 0、1、2、3 火。巡演开演前检查完整三首所需火数。默认火不足就停止；选择“使用回复道具补火”后，优先使用小型饮料，不足时使用普通饮料，只补足本轮所需火数，普通饮料可能带来少量余量。不会使用星石，也不会付费续关。

最大次数默认 1，可填 1–999，留空不限次数。不限次数且启用道具补火会持续消耗饮料，直至手动停止、饮料不足或流程出错。

## 自动调整的设置

每次任务仅在第一次演出前调整一次设置；同一任务的后续连续演出与巡演轮次不重复进入设置页。任务将音符速度设为 9.80，音符大小设为 100%，显示与判定偏移设为 0，恢复音符出现位置和默认演出皮肤，关闭镜像与色觉辅助，采用轻量模式并关闭 3D 切入。这些设置保留在游戏中，不会在任务结束后自动恢复。

首次同步根据谱面首键的轨道和颜色跟踪下落；演奏期间继续用多个普通音符平滑校时。因此并非只定位首键后完全盲打，也不会把视觉下落速度当成音乐节拍速度。

## 当前限制与日志

当前版本使用 MuMu 的快速截图接口，暂不支持其他模拟器。目录包含中国服已开放歌曲和实际难度，不能自动解锁歌曲。自由／巡演中暂停、断线、失败或画面无法确认时停止；团队模式确认掉房时按上述策略重进，谱面同步或输入错误仍停止。

点击 MaaBanG 停止后，会通知演奏进程释放正在按住的触点；自由／巡演会尝试暂停，联网演出不自动点击暂停。每次任务的配置、演奏记录和截图保存在 `app/debug/chart_live`。团队报告分别记录房间尝试、重试原因与成功次数。结果判断以正常结束演出为准，不以全连为门槛。

全目录离线检查只能证明谱面可下载、可转换和手势范围有效，不能证明每首歌都已实机演奏。实机覆盖和本地测试包信息见开发验证记录。

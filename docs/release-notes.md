## MaaBanG v0.5.2

下载 Windows x64 ZIP，完整解压后运行根目录的 **MaaBanG.exe**。升级前退出旧版本；配置和谱面缓存继续复用 `%USERPROFILE%\.maabang`。

### 领取礼物与任务奖励

- 修复礼物已经领取，却因先弹出“获得服装”等通知而等待“一键领取完成”超时的问题。领取后先处理连续通知，再确认已返回列表。
- 礼物和任务奖励共用领取结果处理，保留超时、有限重试和未知弹窗停止机制，避免重复提交或点击背景页面。
- 任务奖励不再使用固定分类名单。按页面实际显示的标签顺序逐页检查，存在可领内容时点击“全部领取”，自动滚动覆盖屏幕外的标签。
- 两行标签按屏幕位置合并；截断标签滚动到完整可见后再处理。标签文字仅用于去重、页面核对和日志，不作为领取白名单。
- 修复遗漏最上方活动任务奖励的问题。没有领取按钮的页面根据实际锁定或邀请状态处理。

### 验证

- 本地 35 项日常任务测试、7 项通用通知测试通过。
- 使用此次“获得服装”失败截图进行真实识别回放，覆盖直接弹出服装、普通领取确认后弹出服装、仅普通领取确认三种顺序。
- MuMu 实机确认漏领的 10,000 金币到账；最终通用遍历流程覆盖当前全部 7 个任务标签，并正常返回主页。
- 礼物已领空，当前实机验证覆盖空列表正常结束；服装通知分支通过失败截图回放验证。

本版保留 v0.5.1 的共享配置、共享缓存和按需下载谱面功能。协力演出仍未开放。

## MaaBanG v0.6.22

指定谱面直接演出支持协力模式的准备按钮。

### 修复与改进

- 自动识别普通“演出开始”和协力“准备开始／准备完毕”按钮，无需新增模式设置。
- 协力准备按钮只点击一次，随后按联网演出逻辑等待其他成员、处理等待提示并同步首键，避免沿用单人开场等待时限。
- 开演前再次检查准备按钮；准备页消失或开演方式变化时停止，不重复点击。
- 保持用户指定歌曲和难度、沿用当前游戏设置、每次一首，以及谱面输入完成即结束任务的边界；不等待或操作结算页。

### 验证范围

- 自动化回归覆盖两种开始方式、协力按钮文案、准备页变化、等待成员、技能首音、单次点击、失败处理及完成边界，并使用已有协力准备页截图验证 OCR。
- 本次未进行实际联机演奏验证。自动化测试、CI 和发布包检查不代表实机游玩结果。

完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。

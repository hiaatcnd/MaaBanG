## MaaBanG v0.4.0

下载 Windows x64 ZIP，完整解压后运行根目录的 **MaaBanG.exe**。

### Maa代打演出（实验性）

新增按 Bestdori 乐谱发送触控的独立任务，不使用游戏内置自动演出额度。支持中国服目录中的 734 首歌曲、3070 张已开放谱面，歌曲需在游戏内解锁；首次使用某张谱面需联网下载。

- 支持自由演出、三首独立选曲和难度的自由巡演，以及自动读取固定歌曲的课题巡演。
- 每首可选 0–3 火、最大演出次数，以及火不足时使用回复道具；补火不使用星石。
- 五档非零随机偏差，时间与位置采用以零为中心的截断正态分布，小偏差更常见。同押和长按、滑条保持一致的偏移。
- 首键视觉定位后按谱面执行，演奏中持续平滑校时；改善首键短暂漏检时的容错，并增加失败轨迹和截图。
- 每次任务仅在首次演出前设置速度 9.80、默认皮肤、轻量模式等，连续演出复用设置。这些设置会保留在游戏中。

目前使用 **MuMu 安卓 15、16:9 横屏**。已确认 **2560×1440** 会自动缩放到内部 1280×720 识别，触点由框架映射回设备坐标，无需修改模拟器分辨率。其他模拟器暂不支持；不保证全连，可能出现 MISS，较大的随机偏差也可能导致演出失败。

### 选歌与界面改进

- Maa代打演出和清火自动演出均无需收藏。用户只选歌曲和难度，程序在游戏内按乐队及该曲 EXPERT 等级筛选，加快查找。
- 非 EXPERT 演出会在找到歌曲后解除等级限制，再切换实际难度，避免因等级不同隐藏目标歌曲。
- 任务统一命名为“Maa代打演出”，配置去掉“谱面”前缀，修复最大次数重复显示两行。
- “解锁默认3D演出服装”更名为“解锁3D演出服饰”，解锁范围不变。

### 验证范围

120 项自动化测试、资源与 JSON Schema 检查通过。实机覆盖自由演出、自由巡演、课题巡演及回复道具补火；游戏内乐队和精确等级筛选已单独实测。

3070 张谱面通过此前全目录离线检查；本次正态偏差修订另通过 56 张代表谱面五档检查和 12,000 个音符的分布检查。离线检查不等于所有歌曲实机演奏。首键容错及正态偏差最后修订已做自动化验证，未重新覆盖完整实机演出。

使用说明见仓库 `docs/zh_cn/chart_live.md`，验证细节见 `docs/zh_cn/develop/chart_feature_validation.md`。

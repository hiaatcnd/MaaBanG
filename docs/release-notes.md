## MaaBanG v0.7.0

新增独立的 Bestdori 档案工具，支持读取游戏卡牌、核对修改并同步档案。

### Bestdori 档案工具

- **独立工具页**：从左侧“工具”打开，无需加入任务队列。未连接模拟器时也能导入、编辑和导出；登录状态在页面顶部显示。
- **选择更新范围**：按乐队、成员、星级选择，游戏内同步应用成员和星级筛选。读取可随时停止并保留已有记录；翻页核对重叠位置，避免重复识别、遗漏和无进展循环。
- **卡牌资料与核对**：展示 Bestdori 特训前后小图和当前技能等级对应的完整技能效果。底稿、读取原值和合并目标同表对照，目标行可直接编辑；变化数值着色，可只看有变化的卡牌。
- **批量调整与还原**：可分别指定等级、技能等级和星光等级，对勾选卡牌按读取原值、当前值和指定值取最大值，受卡牌上限限制；一键恢复读取原值。
- **导入导出与云端保存**：可用已有本地或云端档案作底稿，同一卡牌冲突时选择覆盖或逐项取最大值。支持导出、复制、新增云端档案及替换当前云端底稿；替换前备份、复核云端状态，保存后读取确认。
- **缓存与恢复**：缓存卡面、技能及核对记录；读取原值与修改值分别保存。修复预览版恢复缓存时等级、特训缺失的问题，匹配的原始扫描可用于恢复。

### 使用范围

- 游戏读取目前仅支持中国服，使用主页当前选择的设备；与该实例的普通任务互斥。只浏览卡牌，不练习、不特训、不消耗材料。
- 范围外卡牌、故事状态、卡面选择、排除设置、区域道具和角色潜能随底稿保留。道具与角色潜能暂不自动扫描；卡牌星光等级与角色潜能是不同字段。
- 登录凭据仅保留在当前工具进程内，不保存账号密码或登录 Cookie。

### 验证范围

- 覆盖档案编解码、合并、云端写入保护、缓存恢复、真实截图离线识别、滚动重叠和终止条件的自动化验证；原生界面验证编辑、还原、变化筛选、卡面布局和完整技能显示。
- 预览版已完成中国服 Morfonica 4／5 星 64 张卡、5 页的游戏扫描。后续缓存与界面修复通过自动化和打包运行环境检查；云端替换使用模拟服务验证，未对真实账号执行替换测试。
- 正式发布另由 resource／windows CI 检查，并独立验证正式下载包的校验和、源码一致性、运行环境及 Agent 启动。自动化与安装包检查不等同于所有游戏场景的实机覆盖。

完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。

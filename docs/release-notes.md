## MaaBanG v0.6.6

为 issue #20 加入筛选防护，并移除代打启动时对 MuMu 安卓 15 的硬编码依赖。原问题仍待反馈者验证，本版不宣称已消除所有误选情况。

### 挖矿筛选防护

- 等待筛选面板停止滚动后再识别“未 FULL COMBO”；识别后画面若发生位移，丢弃旧坐标并重新识别。
- 点击后重新定位“未 FULL COMBO”，核验该选项自身的选中状态，避免只检查旧坐标的颜色。
- 面板持续移动或选中状态无法确认时停止，避免继续带着错误筛选进入演出。

### 代打连接

- 演奏进程复用当前 MaaFramework 连接的截图增强配置，不再调用 MuMuManager 或指定安卓 15 DLL 路径。
- 缺少增强配置时通过框架发现当前 ADB 地址，要求唯一匹配，避免连接到其他实例。
- 仍需启用 EmulatorExtras 截图增强、支持 MaaTouch 多点触控，并使用 16:9 横屏。启动失败时显示具体准备失败原因。
- 开发探针及使用说明同步更新。

### 验证与限制

- 394 项单元测试及 JSON Schema 校验通过。
- MuMu 安卓 12、原生 1280×720 测试实例上，新逻辑五种难度共 15 次筛选通过；两首 EASY 为 ALL PERFECT，其中一首从筛选到结算返回首页全程自动完成。
- 同实例旧筛选逻辑五种难度各测一次，未复现 SS 误选。截图定位与实际点击之间坐标失效是基于原日志的判断，不能认定 1280×720 本身是根因，也不能据此保证原 issue 不再发生。
- 雷电完整演出尚未实机验证；安卓 15、2560×1440 原有实例仅验证连接与增强截图。新账号首次教学、速度确认和奖励选择弹窗需先完成设置。
- 完整解压后运行根目录 MaaBanG.exe，也可使用整包更新；用户配置与谱面缓存继续保存在 %USERPROFILE%\.maabang。

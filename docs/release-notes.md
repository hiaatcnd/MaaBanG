## MaaBanG v0.6.2

新增 MaaBanG 整包自动更新。**从 v0.6.1 或更早版本升级时，请先退出旧版，手动下载并完整解压本版，运行根目录的 MaaBanG.exe。** 原有配置和谱面缓存继续复用 `%USERPROFILE%\.maabang`。

### 更新功能

- 设置中可“检查 MaaBanG 更新”或“更新 MaaBanG（整包）”。开启“自动更新 MaaBanG（完成后重启）”后，启动检查时会自动下载安装；默认仅检查版本，不自动安装。
- 从 GitHub Releases 下载完整包，一并升级启动器、定制界面、Python、MaaFramework、Agent 和资源，避免组件版本混用。
- 验证远程 SHA256、安装包结构及逐文件清单；拒绝损坏、不完整或路径不合法的包。兼容较深的依赖目录与中文、空格路径。
- 等待旧界面退出后替换安装目录，保留完整旧包备份。新版内置 Python、框架、OCR 和 Agent 通信检查失败时恢复旧包；检查通过后自动重启。
- 支持将含更新清单的完整 ZIP 拖入界面进行本地更新。配置和谱面缓存不随安装目录替换；自定义 `MAABANG_DATA_DIR` 应放在安装目录之外。

### 验证与使用边界

- 13 项 Windows 更新／回退测试与 6 项共享数据测试通过，覆盖损坏包拒绝、长路径、等待旧进程、配置保留与失败回退。
- 已在隔离副本中完成 v0.6.1 到本次验证包的真实整包替换，1,851 个文件校验一致，旧依赖移除、旧包备份和共享数据保留，包内 Agent 检查通过。
- Windows CI 增加更新／回退测试及真实包内运行环境升级检查。正式产物下载后的独立校验与联网更新验证结果另行记录。
- 安装目录及其父目录须可写，磁盘应留足新包、旧包备份与下载 ZIP 的空间。更新期间不要移动目录；突然断电时可能需要从备份手动恢复。
- 本版没有修改游戏任务逻辑；更新验证不连接游戏，也不消耗游戏资源。

## MaaBanG v0.7.6

修复“开始唤醒”进入连续开场剧情后，被当作未知页面等待 60 秒并停止的问题。

### 开始唤醒

- 接入已有的通用剧情菜单与跳过识别，按“菜单 → 跳过 → 确认”退出开场故事；不依赖角色名、活动标题或对白内容。
- 剧情控件必须同时匹配限定区域内的模板和同一位置的可见文字；遇到弹窗、加载、登录验证或前台用户变化时，不操作背景控件。
- 每次操作后重新识别，相同操作连续五次未推进即停止；保留总超时、100 步上限和连续三帧主页确认。
- 未知启动页的保底点击与等待限制保持不变。

### 验证

- 41 项唤醒测试通过，包含本次失败剧情截图的真实 OCR 和模板回放，以及剧情菜单、跳过确认、弹窗隔离、卡死与前台变化回归。
- 已在 MuMu 实例 1 实测：从原先卡住的生日剧情打开菜单、跳过并确认，继续处理通知／奖励页面，最终连续确认主页并成功完成唤醒。此验证仅运行唤醒，没有执行演出或消耗体力。

完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。更新后重新启动 MaaBanG。

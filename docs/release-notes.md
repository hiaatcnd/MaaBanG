## MaaBanG v0.7.12

修复协力匹配超时后无法取消“匹配中”弹窗，导致演出和后续每日任务连续失败的问题。

### 匹配超时恢复

- 识别匹配标题、寻找房间或对手的提示及弹窗内唯一的“取消”按钮，避免将其当作未知弹窗一直等待。
- 用新截图确认目标稳定后取消；点击后等待页面变化，仍为同一匹配弹窗时最多补点两次，每次至少等待 3 秒。总恢复时间仍限制在 30 秒内，并响应停止请求。
- 弹窗消失后继续确认退出页面，再重新匹配；不把背景房间标题或控制器返回成功当作取消完成。
- 目标变化时重新确认；未知弹窗、消费选择和不明确的按钮保持停止保护，不重复计算已完成轮次。

### 验证与边界

- 使用 2026-11-09 的失败截图进行真实 OCR 回放，新增点击无效、延迟生效、页面变化、重试耗尽、停止请求和不重复操作的回归测试。
- 当天前 5 轮协力已经完成；故障发生在下一轮匹配阶段。自动测试和截图回放不代表已完成真实游戏重跑。

完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。更新后重新启动 MaaBanG。

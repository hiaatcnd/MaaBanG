## MaaBanG v0.6.14

修复特殊首键无法锁定的问题，新增可选的“避免 Full Combo”功能，并整理任务说明。

### 修复与新增

- 修复技能长按／技能滑条首键颜色识别：单人识别金色技能头，联机兼容金色与绿色，保留轨迹身份检查，避免误锁长条尾部。
- 修复 SPECIAL 方向首键识别：向左识别紫色，向右识别橙色，继续使用原有左右触控编排。
- “Maa代打演出”新增“避免 Full Combo”开关，默认关闭。开启后每首跳过最后一个独立普通键或滑键，完整演奏所有长条、滑条及其滑键尾端；同押只跳过一个符合条件的音符。若没有可跳过的独立音符，则在开演前停止。
- 整理任务与选项说明，明确启动页面、运行条件、资源消耗、计次规则和结束位置；生成工具共用文案，更新界面时保留一致说明。

### 验证

- 首键修复已有 MuMu 0 火实机验证：技能长按 NORMAL、左方向 SPECIAL、右方向 SPECIAL 均 ALL PERFECT；另一次 EXPERT 为 760 PERFECT、1 GREAT、0 MISS，FULL COMBO。
- “避免 Full Combo”通过正式 ChartLive 入口完成三局 0 火实机对照：EASY 关闭时 ALL PERFECT；EASY 和 NORMAL 开启时各恰好 1 MISS，均正常结算。EASY 末尾长条完整演奏，其余触控与同种子的完整计划逐条一致。
- 联机技能长条、末尾方向滑键、长条滑键尾端、同押与全长条拒绝策略由自动化测试覆盖，本次未逐项新增联机或实机验证。详细记录见开发文档。

完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。已有配置继续保留。

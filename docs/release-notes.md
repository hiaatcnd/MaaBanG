## MaaBanG v0.6.5

补齐此前未发布的两项修复，并保留 v0.6.4 的活动免费招募功能。

### 多页任务奖励

- 每个任务分类从第一页开始逐页检查和领取，全部页面检查完成后再切换分类。
- 当前页没有可领取奖励时继续检查后续页；页面停留在第二页或第三页时先返回第一页。
- 每次翻页都确认目标页码，识别异常时停止，避免漏页或重复点击。

### 演出预先设置任务迁移

- 修复旧实例更新后“演出预先设置”任务可能缺失或没有位于首位的问题。
- 每个实例只迁移一次，保留其他任务顺序、勾选状态及已有预设选项。
- 迁移完成后，用户再次排序或删除任务会被保留，不会每次启动强行恢复。

### 验证与使用

- 383 项测试及 JSON Schema 校验通过，包含三页任务截图和分页流程回归。
- MuMu 实机逐页检查 1/3、2/3、3/3，在第 3 页领取 20 个流光碎片；检查完 8 个分类后返回主页。
- Windows 构建检查实际打包 UI 的五种任务迁移场景，使用独立临时数据，不启动游戏任务。
- 完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。原有配置与谱面缓存继续保存在 %USERPROFILE%\.maabang。

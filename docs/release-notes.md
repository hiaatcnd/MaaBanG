## MaaBanG v0.5.4

下载 Windows x64 ZIP，完整解压后运行根目录的 **MaaBanG.exe**。升级前退出旧版本；配置和谱面缓存继续复用 `%USERPROFILE%\.maabang`。

### 演奏同步与恢复

- 统一首键与持续跟踪的时间基准，改善开场 PERFECT 率低、随后才逐渐校正的问题；补充发亮长按键头识别和稀疏谱面的同步证据。
- 短暂调度卡顿后释放触点、跳过过期手势，从后续完整音符继续。超过 2 秒或 10 秒内反复发生四次的阻塞仍停止；不补发积压触控，不使用续关。
- 开演前关闭 MV、3D 演奏和 Cut in；修复团队演出的火数预览误读，并在重读时核验房间、歌曲与难度。
- 演奏日志补充实际加载模块、SDK 完成耗时、相位校正及恢复记录。

### 选歌与舞台挑战

- FC 挖矿直接按难度筛选未 FULL COMBO，保留列表位置并缩小滚动幅度，减少反复进出和跳过歌曲。其他演出任务会清理继承的歌曲筛选。
- 舞台挑战按乐队显示顺序、关卡编号升序处理；支持“未完成”和“未满星”。满星乐队整体跳过，非目标关卡优先从列表星数批量排除。
- 修复舞台挑战奖励中的“星石招募券”被误判为招募交易，导致弹窗无法关闭的问题。

### 成员故事与配置

- 去除头像匹配和名称 OCR 一致性对故事阅读的阻拦；名称仅用于日志，遍历继续按卡片画面去重。
- “成员星级”改为 1★～5★ 多选标签，直接使用游戏稀有度筛选。默认一、二、三星，全部取消则跳过任务；关闭练习时也生效。
- 练习与材料解锁合并为“练习至满级”。关闭时只读已解锁故事；开启后允许练习、自动特训和材料解锁，仍核对等级、星级与材料数量。
- 配置显示名称去掉“挖矿”前缀；最大演出次数统一默认留空不限，已有手动保存的次数保留。

### 验证与范围

- 288 项本地自动化测试及资源／界面格式校验通过。
- MuMu、0 火、EXPERT、极小非零偏差下，三首同步回归分别以 641、532、691 个 PERFECT 完成 ALL PERFECT 并正常结算；不代表全曲库或所有环境均能全连。
- EASY 与 EXPERT 各注入三次 627ms 调度阻塞，六次均恢复并完成结算。此验证不等同于修复 SDK 永久卡死、首键完全漏锁或团队断线后的演奏重接。
- 舞台列表选关、成员星级筛选、原名称误停卡片及取消返回路径经过实机验证。成员故事本轮没有重新执行整轮耗材养成；星级标签到任务参数的传递另经实际 SDK 校验。协力演出仍未开放。

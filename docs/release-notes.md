## MaaBanG v0.6.11

新增独立任务 **更新歌曲列表**。运行后联网更新歌曲资料，并动态刷新界面选歌选项及 Agent 内存目录，无需重启 MaaBanG。

### 使用方式

- 在任务列表添加“更新歌曲列表”并运行，默认不勾选。
- 同步清火自动演出、代打演出、指定谱面直接演出、协力与挑战演出的选歌列表及联动难度。
- 国服选歌范围保持不变；全服歌曲资料仅用于离线识别。更新任务不操作游戏，不下载音频或谱面。
- 按原歌曲保留各实例的选择、勾选状态与任务顺序；原歌曲或难度已不可用时取消相关任务勾选并提示重新选择。
- 下载、校验失败时保留原列表；文件替换失败时回滚。多个实例不能同时写入曲库。

### 验证

- 真实下载验证：752 首国服可选歌曲、822 首全服识别资料；准确抓取时间以安装包目录元数据为准。
- 覆盖下载失败、取消、写入回滚、并发保护、Agent 热加载与框架任务成功回调。
- 界面编译及选歌保留逻辑验证通过，包含排序变化、歌曲改名、难度变化和歌曲移除。
- 本次为歌曲元数据与界面更新，不新增打歌或游戏操作行为；未将这些测试视为新增曲目的实机演奏验证。

完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。

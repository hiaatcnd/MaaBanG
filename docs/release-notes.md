## MaaBanG v0.6.23

进一步缩短联网演出的谱面准备和演奏进程启动时间。

### 修复与改进

- 缓存谱面读取完成后直接继续准备，省去重复截图和页面识别；实际下载仍检查页面变化、用户停止和准备超时，开演前继续核对当前歌曲与难度。
- 演奏进程初始化期间保留前台、停止和房间超时检查，减少主流程与初始化争用识别资源。进程就绪后继续执行最终确认和画面监视交接。
- 并行加载识别资源、连接触控及监视控制器，每个控制器仍先连接再截图；所有初始化结果通过验证后才允许开演。
- 记录谱面读取、进程准备、最终核对及开演授权的分段耗时，便于区分本机准备时间与联网等待。

### 验证范围

- 自动化回归覆盖缓存快速返回、下载期间页面变化、停止与超时、初始化失败以及画面监视交接。
- 在同一台 MuMu 设备完成两局 0 火协力 EXPERT 演出并确认结算，未发生卡顿恢复或监视器错误。
- 两次实测均命中缓存：“准备演奏进程 → 发送开演指令”为 1.94–2.14 秒，“确认最终歌曲 → 发送开演指令”为 3.35–3.86 秒。两次歌曲不同，这些数值是本机样本，不含匹配和队友等待，也不代表所有设备的固定耗时。
- 实机验证使用发布前的相同演奏代码；正式安装包另行进行完整性、内容一致性及 Agent 启动验证。

完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。

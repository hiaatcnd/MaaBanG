## MaaBanG v0.7.11

修复近期协力演出、领取任务奖励和技能练习的失败，并统一开发启动器的中文输出编码。

### 协力演出与结算

- 修复已关闭的 3D Cut in 因文字与复选框合并识别、文字框左移一像素而被误判为无法确认的问题；仍核对实际开关状态，不重复切换已经关闭的开关。
- 修复较高的“试炼目标”弹窗未被识别，导致演出完成后结算超时的问题；保留白色面板、分隔线和唯一关闭按钮检查，不自动确认购买或消耗弹窗。
- 演出失败报告增加异常类型及完整堆栈，便于区分识别、结算和同步失败。

### 点击未生效时恢复

- 领取任务奖励：分类点击未生效时，重新识别目标并确认仍停在原分类、位置稳定后，最多补点两次；延迟切换成功后立即继续，不重放已经确认的领取操作。
- 技能练习：同名材料勾选未生效时，在成员、材料、未选中状态和技能预览均未改变的前提下，最多补点两次；观察到选中或预览变化后不重复点击，恢复失败时取消并停止。
- 补点记录原因并响应停止请求；新增延迟生效、页面变化、次数耗尽和避免重复操作的回归检查。

### 编码与开发约定

- 开发启动器及其子进程统一使用 UTF-8 输出，修复 Windows 旧编码环境下中文提示混入同一输出流而导致的解码错误；覆盖中文、日文、表情符号和多级子进程。
- 补充点击结果确认与有限恢复的开发约定。

### 验证与边界

- 使用近期失败截图进行真实 OCR 回放，并覆盖开关已经关闭、试炼目标结算、分类切换和同名材料选择。
- 自动测试及截图回放不代表真实游戏完整运行；此前的演出触控延迟或同步失败不属于本次修复范围。

完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。更新后重新启动 MaaBanG。

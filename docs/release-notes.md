## MaaBanG v0.6.22

指定谱面直接演出支持协力准备按钮，并减少联网演出准备和演奏监视中的重复工作。

### 修复与改进

- 指定谱面直接演出自动识别“演出开始”和协力“准备开始／准备完毕”，只点击一次，随后等待其他成员并按联网规则同步首键；准备页或开演方式变化时停止。
- 联网准备流程合并相同区域的错误识别，复用已确认的歌曲、已选难度和协力准备按钮结果，提前读取谱面，并移除重复的通用 MV 检查。保留新画面检查、歌曲和难度一致性、Cut in、消耗及页面变化校验。
- 演奏监视移除识别动作的默认前后延迟；在演奏进程完成首次有效画面检查后移交画面监视，主流程继续检查前台、停止和房间超时。演奏开始后不再识别已无用途的成员准备提示。
- 维护、账号限制等致命错误优先停止，不再触发退出或重匹配操作；断线仍按原流程处理。联网截图或弹窗检查失败时停止触控，错误截图失败不会覆盖原始原因。
- 指定谱面直接演出仍只演奏用户指定的一首，沿用当前游戏设置，谱面输入完成即结束，不等待或操作结算页。

### 验证范围

- 自动化回归覆盖准备按钮、协力等待、技能首音、单次点击、完成边界，以及联网歌曲／难度／Cut in 校验、错误优先级、画面监视交接和截图失败处理；已有协力准备页截图用于离线 OCR 验证。
- 本次未进行实际联机演奏验证。自动化测试、CI 和发布包检查不代表实机游玩结果。

完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。

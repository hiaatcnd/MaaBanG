## MaaBanG v0.7.2

新增开始唤醒和退出任务，可自动完成模拟器启动、游戏进入与任务结束后的关闭。

### 新功能与修复

- **每日免费招募**：活动免费招募检查结束后直接在当前招募页切换到每日卡池，修复返回主页再进入招募页一次的问题。列表滚动位置变化时会回到顶部查找，已在每日卡池时直接继续；保留免费确认和完成后返回主页的检查。

- **开始唤醒**：自动启动指定 MuMu 实例或自定义模拟器，打开指定游戏应用。模拟器多开实例号与 Android 用户 ID 分开设置；用户 ID 默认 0，应用分身一般从 10 开始。
- **启动页面处理**：处理游戏资源下载、登录奖励、连续活动“下一步”、公告及宣传页关闭。每次点击后重新识别，确认到达无遮挡的主页再执行后续任务；未知页面会停止并保存截图、OCR 和操作记录，便于持续适配。
- **路径与连接设置**：模拟器和 ADB 路径支持文件选择，MuMu 默认安装可自动定位并读取实例地址。补充连接地址和实例号说明，修复说明文字与输入框重叠，唤醒成功后同步上方当前设备。
- **退出任务**：在普通任务之后关闭指定应用／分身、指定 MuMu 实例或整个 MuMu 程序。默认沿用本轮唤醒目标，也可单独指定。整程序退出会关闭该安装下的全部实例；单独执行退出不会先启动模拟器，已关闭的指定实例视为完成。

### 验证与适配范围

- 已在本机 MuMu 验证原应用、用户 10 分身和模拟器冷启动；保存了首次资源更新、登录奖励及活动页样本，并加入真实 OCR 回放测试。
- 已实测关闭用户 10 分身、关闭实例 1 和重复关闭；实例 0 原应用保持运行。整程序退出的命令顺序和失败处理有自动化覆盖，本轮未实机关闭全部运行实例。
- 实例及整程序关闭目前适配新版 MuMu（mumu-cli）；其他模拟器支持通过 ADB 关闭指定应用。客户端安装包更新、账号验证及未适配启动页面仍需人工处理。
- 发布检查包含资源和 Schema 校验、全量单元测试、Windows 构建与 Agent 启动、整包升级、任务迁移，以及正式包输入布局／退出目标继承验证。一次性活动截图及 OCR 回放材料保留在本地，不随公开源码提交。

完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。新增任务默认不勾选，请按需要添加“开始唤醒”和“退出”。

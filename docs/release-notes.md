## MaaBanG v0.5.3

下载 Windows x64 ZIP，完整解压后运行根目录的 **MaaBanG.exe**。升级前退出旧版本；配置和谱面缓存继续复用 `%USERPROFILE%\.maabang`。

### Maa 代打首键识别

- 修复《DEPARTURES》EXPERT 等谱面中，粉色滑键发亮后被漏识别，误选后续音符并触发“首键倒退或身份变化”停止的问题。
- 增加浅粉色键头识别；原有饱和色键头仍优先使用原坐标，避免改变已有的同步时机。
- 保留首键身份检查、锁定精度要求及非零随机偏差；没有放宽保护来跳过错误。

### 验证与范围

- 235 项本地自动化测试通过，包含本次实机连续截图回放，以及白色、灰色和其他音符颜色的排除测试。
- MuMu 自由演出、0 火、速度 9.8、中等随机偏差下，原代码复现同一首键错误；修复后《DEPARTURES》EXPERT 整曲完成，得分 2,603,036（SS），正常结算并返回主页。
- 团队演出使用同一首键识别模块，但本轮未重新进行团队演出实测。此次不包含团队演出失败后的恢复流程变更，不保证全连。

本版保留既有的礼物与任务奖励领取修复、共享配置缓存及按需下载谱面功能。协力演出仍未开放。

## MaaBanG v0.5.1

下载 Windows x64 ZIP，完整解压后运行根目录的 **MaaBanG.exe**。本版修复日常任务、挖矿与演出流程中的识别问题，并让配置和谱面缓存跨版本复用。

### 配置与缓存

- 任务、设备和实例配置统一保存在 `%USERPROFILE%\.maabang\config`，谱面保存在同目录下的 `cache\charts`，换包或升级后继续复用。
- 首次启动优先迁移当前包的配置，并合并相邻 MaaBanG 包中的旧谱面缓存；原文件保留，已有共享配置不会被旧包覆盖。
- 同一数据目录只运行一个界面实例。需要独立配置时，可通过 `MAABANG_DATA_DIR` 指定另一个目录；升级前请退出正在运行的旧版本。

### 演出

- 团队演出不再提前下载整个曲库。识别最终歌曲和难度后，先读取共享缓存，缺失时只下载对应谱面。
- 下载期间持续检查房间状态；谱面准备超过 12 秒、下载或校验失败时退出房间并停止任务，避免使用过期页面提交准备。
- 修复滑动首键接近判定线时颜色变浅而漏识别的问题，保留原有同步精度和首键身份检查。
- 修复结算、等级提升、故事解锁及歌曲达成报酬一览弹窗处理，避免操作仍可见的背景按钮。

### 日常与挖矿

- 修正任务奖励入口识别，以及限时任务入口的状态判断。
- 多候选成员按稳定的屏幕顺序逐一进入、核对身份后处理，适配特殊图标、卡片变化和轻微界面位移。
- 取消故事材料解锁后，确认弹窗已关闭再返回，避免重复点击或误操作背景。
- 舞台挑战推荐编组明确提示成员不足时跳过该挑战；未知结果停止，不继续盲目开演。

### 验证与限制

225 项自动化测试通过。MuMu 安卓 15 实机按每轮 3 火、禁止补火运行团队演出至剩余 2 火，确认自动停止并返回主页；共 8 轮，其中 7 轮正常完成，1 轮暴露滑动首键漏识别。该问题修复后，同曲《ドレミファロンド》EXPERT 的 0 火整曲复测通过，随后继续团队演出并验证火不足停止。

共享配置迁移、跨包单实例和缓存复用已验证。实机与截图回放覆盖本次遇到的弹窗、成员选择和挑战提示；材料解锁、练习等耗材分支未在本轮重新完整实测。协力演出仍未开放，不保证全连；设备性能和随机偏差可能导致 MISS。

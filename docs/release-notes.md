## MaaBanG v0.3.2

下载 Windows x64 ZIP，完整解压后运行根目录的 **MaaBanG.exe**。请使用本版完整包，旧试用 ZIP 不含全部修复。

### 启动响应优化

打开后仍自动刷新设备列表并连接模拟器，优先匹配上次保存的设备。耗时的设备扫描移到后台，避免扫描期间窗口无响应；无需手动点击刷新才能连接。主动配置的自动运行保留原有行为。

本机测试约 2.13 秒出现窗口，连续 25 秒响应检测无超时，并成功连接 MuMu、启动 Agent。设备扫描及连接总耗时仍取决于环境。

### 每日首次演出奖励修复

修复巡演第一首结束后的“每日演出报酬完成”弹窗遮挡剩余自动次数，导致清火任务及后续任务失败的问题。现在先确认关闭弹窗，再识别下一首准备页和剩余次数。普通结算仍支持该弹窗。

已在问题现场验证关闭奖励弹窗、识别第 2 首准备页及剩余 9 次；未额外开始演出。全部 72 项单元测试通过。

### 默认顺序与文档

默认任务顺序调整为：清火自动演出 → 每日免费招募 → 领取主页礼物 → 领取任务奖励 → 解锁默认3D演出服装 → 米歇尔贴纸交换。已有用户保存的任务顺序不强制覆盖。

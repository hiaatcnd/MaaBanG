## Windows 独立运行版

下载 `MaaBanG-*-win-x64.zip`，完整解压后运行 `MaaBanG.exe`。内置 Python、MaaFramework 和 OCR；无需 VS Code、Python 或 uv。模拟器及游戏需自行准备。

- 自动补齐默认 3D 演出服装，支持全部成员、指定乐队或指定成员。
- 用户输入每位角色目标数量；可先选择仅检查模式。
- 自动领取服装收集奖励；收集任务全部完成的角色快速跳过。
- 按缺少件数连续解锁；裁缝套装或金币不足、结果不明确时停止。
- 解锁后选择“不变更”，保持原穿搭。

当前验证环境为 MuMu、中国服、横屏 1280×720。首次运行请先完成游戏登录，并从主页、乐队、评级或服装列表开始。使用说明见包内 README.md；校验文件为 SHA256SUMS.txt。

修复 Windows 默认临时目录导致的 Agent 启动失败：使用 MaaBanG.exe 启动时自动设置软件进程的临时目录，不修改系统设置。UI 使用“目标数量”，不再显示任务描述中的变量 x。

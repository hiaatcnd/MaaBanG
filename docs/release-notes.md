## MaaBanG v0.3.1

下载 Windows x64 ZIP，完整解压后运行根目录唯一启动程序 **MaaBanG.exe**。内置界面、Python、MaaFramework 和 OCR，无需额外安装。

### 清火自动演出

- 接入 Bestdori 中国服离线歌曲目录，本版提供 734 首可选歌曲；同名歌曲按乐队区分。
- **仅从游戏内“收藏→所有”选歌，请先在游戏里收藏目标歌曲。界面目录不代表已经收藏，未收藏的歌曲无法找到。**
- 难度候选随歌曲变化，只显示目录中中国服已开放的难度；旧配置中不可用的 Special 回退至 Expert。
- 修正“最大演出次数”的重复标题；留空仍表示运行到自动额度不足或火不足策略要求停止。

### 日常任务与启动程序

- 米歇尔贴纸交换利用可交换项目置顶规则，当前分类已无可交换项目时立即结束，不再向下翻页。
- 所有任务正常完成后返回主页，包含目标数量为零、未选交换分类等无需处理的情况；异常停止保留现场。
- 使用最终版丸山彩粉色图标，移除重复图标素材。
- 根目录只保留 MaaBanG.exe，界面和依赖放在 app/；配置、日志、报告分别位于 app/config/、app/logs/、app/debug/。请完整解压，不要单独复制 exe。

### 验证与范围

通过单元测试、资源与接口校验，以及 Windows 独立包 Agent 握手检查。已有歌曲演出流程此前已实机验证；新增目录歌曲及同名歌曲版本未逐首实机验证，游戏文字或目录差异可能导致找歌失败。目录来源与筛选规则见包内 docs/zh_cn/develop/song_catalog.md。

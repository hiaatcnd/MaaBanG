## MaaBanG v0.7.3

修复“开始唤醒”在登录过程中偶发误报“游戏离开前台或切换了应用用户”的问题。

### 修复

- Android 权限组件短暂接管前台，或暂时读不到前台时，暂停点击并等待最多 3 秒。确认原用户的游戏恢复前台后，重新截图识别再继续。
- 点击前或主页确认时遇到前台切换，会丢弃旧画面的按钮和主页确认计数，避免使用过期坐标或过早宣告唤醒成功。
- 切换到其他应用或其他 Android 用户仍立即停止；权限页面持续停留时提示人工处理，等待期间支持用户停止任务。
- 在唤醒记录中补充前台等待、恢复、身份不符及超时事件，便于定位后续问题。

### 验证

- 已覆盖登录后短暂权限切换、点击前切换、通知处理与主页确认时切换、持续权限页面、前台信息缺失、错误用户／其他应用及用户停止。
- 本地启动页面真实 OCR 回放通过；此次未新增实机冷启动验证。

完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。更新后重新启动 MaaBanG，使唤醒流程加载修复。

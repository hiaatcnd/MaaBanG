## MaaBanG v0.6.3

新增独立的“演出预先设置”任务，统一保存演出参数、Fever 印章开关及 0–3 火档位。首次使用请先运行该任务，再运行代打、内置自动或挖矿。

### 演出与任务修复

- 演出任务沿用游戏已保存的参数与 Fever 状态；每次任务只读取一次火数，不再反复修改或自动降火。原有补火道具策略保留，CP 挑战仍独立设置 CP 消耗。
- 每首开演前关闭 3D 演出、MV 和 3D Cut in。修复 A to Z 的 FILM LIVE MV 文本被截断、无法切至 OFF 的问题。
- 联网首个技能音符兼容普通音符配色；首键锁定截图延后到触控结束保存，避免编码影响首次触控。
- 免费招募兼容没有“分享”按钮的五星成员全屏揭示页，继续采用有界重试与防重复提交检查。

### 歌曲目录与发布要求

- 本次刷新后国服可选歌曲为 747 首，全服离线识别目录为 822 首。新增国服曲目：メロウ、DAY×DAY、革命道中。用户选歌列表仍仅提供国服歌曲及已开放难度。
- 每次打包强制在线更新国服／全服目录、界面歌曲候选及 CSV；更新失败即停止构建，不回退旧目录。
- Windows 发布检查对刷新后的源文件执行全量测试和格式校验。目录记录获取时间、歌曲及乐队数据哈希；游戏运行时仍使用包内元数据。

### 验证与使用

- 迷星叫与 A to Z 均以 EASY、0 火、Fever 关闭实测，MV／3D 为 OFF，分别获得 73／173 PERFECT，其他判定均为 0。
- 两首实测通过乐队列表定位歌曲，绕过了既有等级筛选滑块不收敛问题；不代表该选歌入口已修复。未做帧率基准测试。
- 本地 Windows 测试包通过 CRC、逐文件清单、源码一致性、解压及 Agent 启动检查；正式 Release 下载后的验证另行报告。
- 完整解压后运行根目录 MaaBanG.exe；v0.6.2 用户也可使用整包更新。配置与谱面缓存继续保存在 %USERPROFILE%\.maabang。

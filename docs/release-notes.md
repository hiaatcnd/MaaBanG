## MaaBanG v0.6.14

修复以技能长按或技能滑条开头的谱面无法锁定首键、漏键掉血后停止的问题。

### 修复

- 首键颜色判断同时处理技能单点、技能长按和技能滑条，单人演出正确识别金色技能键头。
- 联机场景中的技能长按／滑条兼容金色和普通绿色键头，并继续检查连续轨迹，避免误把长按尾部或后续音符当成首键。
- 共用首键同步逻辑的自由演出 FC 挖矿、Maa 代打、舞台挑战和指定谱面直接演出均使用此次修复。

### 验证

- MuMu 0 火实机：《過去を喰らう》NORMAL，259 PERFECT、0 其他判定，ALL PERFECT。
- MuMu 0 火实机：《八芒星ダンス》EXPERT，760 PERFECT、1 GREAT、0 GOOD/BAD/MISS，FULL COMBO。
- 首键回归覆盖技能长按／滑条、普通单点／长按、同拍优先选择、尾部技能标记、联机颜色兼容、白色／其他键色干扰和错误轨迹拒绝。
- 联机兼容部分经过录制画面回放与单元测试，未新增联机实战验证。

完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。已有配置继续保留。

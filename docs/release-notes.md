## MaaBanG v0.6.10

新增独立任务 **指定谱面直接演出**。用户停在最后准备页、指定歌曲和难度后，程序直接点击演出开始并按对应谱面打一首。

### 使用方式

- 先在游戏中选好歌曲、难度和乐队，停在点击“演出开始”即可打歌的最后准备页。
- 在任务列表添加“指定谱面直接演出”，选择同一首歌曲、难度和随机偏差，启动任务。
- 程序先获取并校验对应谱面；已有缓存时复用。演奏进程就绪后只点击一次开演，完成一首后停在结算页。
- 不识别曲名和难度、不导航选歌、不循环开演、不补火；不会更改速度、皮肤、火数、Fever、内置自动、MV 或 3D 设置。请提前应用代打推荐设定并关闭内置自动、MV 和 3D 演出；游戏当前显示的消耗保持有效。
- 歌曲与难度由用户保证一致；下载或校验失败、找不到开演按钮时停止，不启动演出。选曲范围仍为中国服已开放歌曲和难度。

### 验证

- 449 项本地回归测试通过；资源与界面 Schema 校验通过。
- 自由演出实测歌曲 773「かぽーんっと極楽☆ 湯〜とぴあ！」EASY，0 火、Fever 关闭、极小偏差：一次点击开演，210 次触控全部成功，135 PERFECT，GREAT／GOOD／BAD／MISS 均为 0；得分 1,801,904，SS。任务确认报酬页后停止，未重复开演。
- 本次实机覆盖上述自由演出单曲；不代表所有歌曲、难度或其他演出模式均已实测，也不保证每次全连或 ALL PERFECT。
- 保留 v0.6.9 的选歌容错、收藏选择及等级滑块修复。正式打包继续刷新国服可选曲库与全服识别目录。

完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。

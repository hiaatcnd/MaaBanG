## MaaBanG v0.2.0

Windows x64 独立运行版。下载 ZIP 后完整解压，双击 MaaBanG.exe；内置界面、Python、MaaFramework 和 OCR。

- 默认 3D 服装按成员整批解锁后领取收集奖励，结束返回主页；不会更换穿搭。
- 新增主页礼物与六类任务奖励领取，完成后返回主页。
- 新增米歇尔贴纸交换：遍历成员、表情、服装、背景、其他，交换可用项目；贴纸不足时停止。
- 新增每日三次免费演出招募，仅使用当天剩余免费次数，不消耗星石或招募券。
- 保留 Windows Agent 临时目录兼容修复，并检查五个动作的注册。

新任务默认不勾选，请从主页启动。贴纸交换会消耗贴纸；确认结果不明时停止，避免重复提交。模拟器、游戏与账号需自行准备。支持中国服、横屏 16:9；使用说明见包内 README.md，校验值见 SHA256SUMS.txt。

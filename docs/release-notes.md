## MaaBanG v0.7.14

汇总成员技能升级、故事挖矿、联网演出、启动流程和整包更新的修复与优化。

### 成员技能升级

- 补充完整卡框识别，避免浅色头像和最后一名成员被漏掉；扫描结束前复核遗漏成员。
- 点击成员、返回列表或选择同名材料未生效时，重新核对当前画面后有限补点。已经观察到选中或经验变化时不重复选择，提交结果不明时不重复消耗。
- 连续确认游戏的“没有可以进行技能练习的成员”提示才认可空列表；识别失败、未知区域和恢复耗尽不再当作完成。
- 重置并确认属性、角色和故事等筛选条件，避免沿用之前的筛选结果而漏升成员；全选点击未生效时不再误判已经恢复。

### 成员小故事与回忆

- 进入培养后确认左侧已切换到“成员一览”，避免沿用技能练习标签；筛选顶部选项已显示时不再反复上拉。
- 全选通过可观察的选中变化确认，并复核角色筛选，避免旧角色条件残留导致漏读。
- 符合等级且材料充足的故事直接解锁，取消额外的解锁开关。“练习至满级”仅控制练级与自动特训，旧配置关闭解锁也不会阻止正常故事解锁。
- 回忆按等级降序检查。关闭练级时，按星级的等级门槛分组，在列表确认后续成员等级不足便结束该组；等级读不清时进入详情复核，开启练级时保留低等级成员。
- 成员点击、排序和筛选确认增加状态核对及有限恢复；补充漏卡检查，滑动未生效不再直接认作列表到底。
- 结束提示区分当前可处理内容已检查与仍有等级不足的回忆未解锁。

### 联网演出与启动

- 匹配、选曲阶段与准备完成后的等待分别最多 3 分钟，避免慢匹配耗尽等待队友的时间。准备复核失败、期限到达或收到停止请求时不授权演奏；重复识别不会续期。
- 退出恢复会等待队友准备遮罩消失，确认暂停按钮可用，再核对暂停、中断和退出确认的实际结果。点击未生效时有限补点，未知弹窗或消费提示不作为退出操作处理。
- 唤醒时识别“新成员登场”后加快跳过展示动画，同时限制单页点击、总点击数与等待时间；登录验证、下载、消费确认等仍按原有规则处理。

### 整包更新与开发维护

- 修复 MuMu 的 ADB 服务将旧安装目录作为工作目录而导致更新失败的问题。仅对已确认与目录占用相关、属于当前用户的兼容 ADB 服务请求正常退出，再重试目录切换。
- 补充 Agent 开发、点击恢复及验证说明，源码自检纳入演出预设动作。

### 验证范围

- 覆盖点击无效、延迟生效、页面变化、停止请求、重试耗尽、等级不明、漏卡与避免重复消耗等回归场景，并使用脱敏实际截图进行识别回放。
- 发布检查包含资源、配置 Schema、完整单元测试、Windows 打包及包内启动、更新、任务迁移和原生界面验证。
- 截图回放和模拟测试不等同于真实游戏整轮验收。本次汇总后的完整故事、联网演出及启动组合流程未重新完成实机验收；日志、个人配置和原始私有截图不随发布提交。

完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。更新后重新启动 MaaBanG。

## MaaBanG v0.6.12

补充任务界面日志，隔离开发配置，并调整指定谱面直接演出的结束时机。

### 任务日志

- 所有 13 个任务补充开始、完成和失败提示，并使用界面可显示的日志格式。
- 增加选曲、谱面读取、演奏等待、结算、奖励领取、招募、挖矿与设置保存等阶段提示。演奏期间每 30 秒提示等待进度。
- 火、CP、材料不足和跳过项目显示具体原因；主动停止显示停止提示，避免误报为执行成功。
- 保留原有诊断报告；日志不增加游戏点击或识别操作。

### 指定谱面直接演出

- 演奏进程确认谱面输入完成后立即结束任务，不再等待或操作结算页。
- 完成提示明确说明“输入完成，未检查结算”；演奏失败或用户停止时不会记为完成，也不会重复开演。

### 开发配置

- 源码 Agent 默认使用项目内 `.maabang-dev/`，正式安装版继续使用 `%USERPROFILE%/.maabang`。
- 新增源码开发入口 `tools/run_dev.py`，启动本地测试包时让界面与 Agent 共用隔离配置；任务列表、勾选、顺序与设备设置可独立保存。
- 支持通过 `--data-dir` 测试全新配置；显式设置的 `MAABANG_DATA_DIR` 仍优先于默认目录。
- 本地测试包须通过开发入口启动才使用开发配置；直接双击包内 `MaaBanG.exe` 仍使用正式配置。使用方法见 README 开发指南。

### 验证范围

- 覆盖全部任务日志入口、异常及资源不足提示、指定谱面结束行为和开发数据目录隔离。
- 实际界面验证开发设置重启后保留，正式配置文件未改变。
- 游戏流程的结束时机由自动化测试覆盖，本次未新增实机演奏验证；不将日志或安装包检查视为游戏结果验证。

完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。正式版已有配置继续保留。

## MaaBanG v0.6.18

修复“清 CP”在余额达到六位数时提示“无法确认数量”并停止的问题。

### 修复与改进

- 选择 CP 消费档位后的余额复核改用与初始检查相同的读取方式，移除该步骤误用的五位数限制，支持 `115272` 等大额余额。
- 复核要求连续两次读数一致，且与选择档位前的余额相同；读数无效、不稳定或余额发生变化时仍会停止。
- 每首消费档位仍为 200／400／800／1600 CP，保留开演前消耗确认和结算后扣点核对。

### 验证范围

- 回归测试覆盖五位数边界、六位数及更大余额、四个消费档位，以及余额变化、不稳定和无效读数时不确认的行为。
- 现有 CP 页面截图继续使用生产 OCR 模型进行回归验证。
- 本次未新增模拟器实机演出验证；自动化测试和发布包校验不代表实机结果。

完整解压后运行根目录 MaaBanG.exe，也可使用整包更新。

## MaaBanG v0.6.0

下载 Windows x64 ZIP，完整解压后运行根目录的 **MaaBanG.exe**。升级前退出旧版本；配置和谱面缓存继续复用 `%USERPROFILE%\.maabang`。

### 协力与挑战演出

- 新增协力演出：沿用游戏当前公开房间，提交“不指定歌曲”，识别最终选曲并按谱面操作；支持 0–3 火、难度选择、掉房重试和结算计次。
- 协力匹配 15 秒后，“立即开始”可用时确认以当前人数开演。SPECIAL 不可用时降为 EXPERT。
- 新增活动挑战演出，消耗 200／400／800／1600 CP。可沿用当前活动歌曲或指定活动歌名／ID；CP 不足时停止，不自动补充。开演前确认歌曲、难度和消耗，结算后核对实际 CP 扣除。

### 离线歌曲目录

- 选歌列表仍只提供中国服歌曲，本次更新至 744 首可选歌曲。
- 联网最终选曲与课题巡演固定歌曲改用随项目保存的全服匹配目录，共 822 首。运行时不刷新目录，也不在匹配失败后临时查询 Bestdori。
- 谱面继续优先使用共享缓存，缺失时仅下载已确认歌曲的对应难度。

### 通用结算处理

- 移除通知标题白名单，不再逐个枚举“某某一览”。根据前景弹窗内部唯一的“关闭／确定／确认／下一步／OK”按钮推进，每次点击后重新观察。
- 自由、巡演及联网结算在排除弹窗遮挡后，直接处理底部推进按钮；购买、补充或多项选择仍交由对应任务处理。
- 修正协力选曲、准备页、火数预览、退房提示及全房间成绩页处理。

### 验证范围

- 313 项本地自动化测试、资源与界面格式校验通过。
- MuMu 实机：挑战演出按每次 200 CP 完成两局；协力 0 火和 3 火均完成全程自动匹配、演奏、结算并回主页。
- 3 火协力《KING》EXPERT：991 PERFECT、9 GREAT、0 MISS，火数 19 → 16，无补火道具、无人工接管。
- 以上不代表全曲库、所有房型或全部资源档位均已实机验证，也不保证 ALL PERFECT。

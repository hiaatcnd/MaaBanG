## MaaBanG v0.7.1

新增同名成员技能升级，完善联网选曲、补火选项和结算弹窗处理。

### 新功能与修复

- **故事弹窗结算**：歌曲故事和乐队登场故事推荐都会选择“稍后再读”并继续结算，兼容标题图标被 OCR 读成额外字符。仍核对弹窗内两个阅读按钮的位置，保留消费弹窗拦截和重复点击上限。
- **同名成员技能升级**：新增独立、默认不勾选的任务。筛选可使用同名成员练习的卡牌，只选择休息室中标有“相同成员加成”的材料，选到材料用完或预览达到技能上限后一次提交；会消耗所选休息室卡牌，不使用练习券。结果无法确认时停止，避免重复提交。
- **联网选择当前歌曲**：协力及竞演自由选歌房间可直接提交游戏当前选中的歌曲，保留该页筛选与收藏状态；最终歌曲、难度和消耗仍在准备页确认。界面选项显示顺序调整，并迁移旧竞演歌曲、收藏设置，保留已保存的选择。
- **补火道具优先级**：Maa 代打演出及挖矿可选择小火或大火优先，默认仍为小火优先；优先道具不足再使用另一种，按实际位置、库存和回复预览操作，不使用星石。
- **联网加载与恢复**：识别准备按钮被加载提示遮挡的最终准备页，等待房间自动开演；无法确认的加载和未知页面使用有时限的退出恢复，避免点击过期坐标。

### 验证范围

- 自动化回归覆盖故事弹窗截图 OCR 与结算继续、联网当前选曲、加载遮挡、配置迁移、补火顺序及同名卡技能练习的正常和异常路径。
- 正式 Windows 包通过受保护 PR 的资源检查、构建、Agent 启动、升级、任务迁移和 Bestdori 原生界面测试后发布；发布后独立下载并核验校验和、文件清单与源码一致性。
